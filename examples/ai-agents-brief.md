# Research Brief: How do AI agents use tools?

## Summary

AI agents use software or other tools to pursue goals and take actions with some level of autonomy [S2]. The packet distinguishes these agents from "tool AI," which performs narrow, specified tasks, but it does not explain the mechanisms by which agents select, invoke, or coordinate tools [S2].

## Key Findings

- Tool use is presented as a defining capability of AI agents alongside goal pursuit and autonomous action [S2].
- AI agents may use software or other unspecified tools, but the packet provides no concrete tool-use examples [S2].
- Agentic AI is contrasted with narrow, task-specific "tool AI," suggesting that autonomy and goal pursuit—not merely access to a tool—are central distinctions [S2].
- Claude is an LLM series used as a chatbot and in AI-assisted software development, but the packet does not establish that Claude itself uses tools [S1].

## Uncertainty

- The packet does not describe how agents choose tools, supply inputs, interpret outputs, handle failures, or decide when to act [S2].
- No disagreement between the sources is evident, but S1 offers little direct evidence about agent tool use and S2 provides only a high-level definition [S1][S2].
- Both sources are brief Wikipedia excerpts, so the evidence lacks technical detail, primary-source support, empirical results, and information about risks or reliability [S1][S2].
